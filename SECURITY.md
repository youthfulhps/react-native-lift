# Security policy

## Supported versions

Only the latest release of `react-native-lift` gets security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately with GitHub's
[Report a vulnerability](https://github.com/youthfulhps/react-native-lift/security/advisories/new)
form (Security tab of the repository).

Include the affected version, the platform (iOS or Android) and the steps to
reproduce. You will get an answer within 7 days. Once a fix is released, the
advisory is published with credit to you, unless you ask otherwise.
